# leetcode

Practice repo for coding challenges (LeetCode, Advent of Code, etc.), kept to
stay sharp.

## Rules

- **Solutions are hand-written.** No AI-generated solution code.
- **AI is used for verification only** — reviewing a finished solution for
  correctness, edge cases, complexity, and idiomatic style after it's
  written, not writing it.

## Structure

- `go/` — solutions in Go
- `typescript/` — solutions in TypeScript

Each challenge gets its own directory under both languages (e.g.
`go/lanternfish/`, `typescript/lanternfish/`), with its own README describing
the problem, and its own test suite.
